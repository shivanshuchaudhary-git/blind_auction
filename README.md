#  Secret Auction Program 

A simple **command-line Secret Auction application** built using Python.
The program allows multiple users to place bids and automatically determines the highest bidder at the end.

##  Features

* Accepts multiple bidders
* Stores bids using a dictionary
* Clears screen effect for privacy
* Automatically finds the highest bid
* Displays winner with bid amount

##  Tech Stack

* Python 3

##  Project Structure

* `main.py` → main auction logic
* `art.py` → ASCII logo

##  How to Run

1️ Clone the repository

```bash
git clone <your-repo-link>
```

2️ Open the project folder

3️ Run the program

```bash
python main.py
```

##  How It Works

1. Each participant enters their name and bid
2. Program asks if there are more bidders
3. When bidding ends, it calculates the highest bid
4. Displays the winner
